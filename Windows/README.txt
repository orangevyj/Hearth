Hearth for Windows 0.2.0

Unzip hearth-windows-0.2.0-source.zip, then:
  powershell -ExecutionPolicy Bypass -File scripts\install-windows.ps1
Start it with hearth.cmd.

Or run hearth-windows-0.2.0-setup.exe, the prebuilt installer (Inno Setup 6).
To rebuild it: build-inno.ps1 on Windows with Inno Setup 6 installed.
